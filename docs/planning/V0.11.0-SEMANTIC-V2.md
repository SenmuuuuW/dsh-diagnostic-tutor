# v0.11.0 Semantic Verification v2

## New constraint

- `point-on-circle` (from v0.10): point/radius consistency, expression or
  timeline-track driven.
- `line-slope`: verifies a line/arrow's slope sign against a trusted reference
  direction; vertical/degenerate samples are excluded, not treated as pass.

Each result has `status` (`pass|fail|unverified|not-applicable`), constraint id
(where implemented), sampled inputs and expected/actual values. Unverified is
never converted to pass.

## Coverage

- 1/5 staged cases had an applicable point-on-circle or line-slope constraint.
- Unit-circle tangent passed.
- Other scenes were unverified.
- Deliberately broken point radius was detected and a real model repair restored
  it 1/1 (v0.10 experiment).

## Not implemented

- sorting state order, binary-search interval, graph traversal invariants:
  current SceneSpec state DSL has numeric/text overrides, not a typed data model
  that can prove algorithm state. We did not add a fake topic-name branch.
- physics trajectory/energy: needs a reference trajectory contract and a
  reliable point/path mapping; not yet.
- economics equilibrium direction: needs trusted supply/demand curves.
- teaching correctness/cognitive load: human review only.

Production approval may display these checks, but passing them does not certify
conceptual correctness.
