# v0.12.0 Tutor → Scene Candidate Bridge

## Model-facing tools

- `udt_scene_candidate_create` — request-only. Validates current project,
  course/node/lesson ownership, source refs, request size, feature flag and
  duplicate requestHash. Never generates, approves or attaches.
- `udt_scene_candidate_status` — read-only candidate state.
- `udt_scene_candidate_attach` — only for an approved, digest-matching candidate
  owned by this conversation/node; requires active attempt; revalidates local
  registry and dynamic-scene flag; duplicate attach is idempotent.

Tool count is now **24** (21 previous + 3 candidate tools).

## Storage and lifecycle

Candidates are local review artifacts, not learner evidence. They live in:

`$DSH_HOME/storages/diagnostic-tutor-scene-candidates.json` (mode 0600)

States: `requested → generating → generated → validating → needs-review →
approved → attached`, plus `failed/rejected/revoked/expired/cancelled`.

Each record stores request context, requestHash, revision, generation spec,
fallback, validation/digest, repair history, review, attach record and expiry.
Content changes after review fail digest verification at attach.

## Generation execution

`scripts/scene-candidate-worker.mjs` is an explicitly labeled **development
bridge**:

```
real research generation → validated scene file
  → scene-candidate-worker (validates + needs-review)
  → scene-candidate-review CLI (human approval)
  → udt_scene_candidate_attach (Tutor tool)
```

The worker does not generate or approve. Production does not expose an automatic
Tutor→model pipeline yet.

## Approval boundary

- No HTTP approve route.
- `scene-candidate-review.mjs` requires interactive TTY and explicit `APPROVE`.
- It writes the local approved registry and candidate status atomically enough
  for local use; digest is recomputed at attach.
- The model cannot approve; only `attach` is model-facing and requires approval.
- Feature flags are separate:
  - `DSH_DIAGNOSTIC_TUTOR_SCENE_CANDIDATES` for request/worker lifecycle;
  - `DSH_DIAGNOSTIC_TUTOR_DYNAMIC_SCENES` for renderer/attach.
Both default off.

## Security tests

- disabled generation flag;
- duplicate request;
- digest mutation after review;
- attachment only from approved state;
- transition refusal;
- cross-project/session checks in tool;
- no approve tool at all.
