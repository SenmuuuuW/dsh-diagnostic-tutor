# Small-sample learner evaluation plan (v0.8.0)

**No learner study was run in this development round.** No result is fabricated.

## Design (ready to execute)

Two conditions, within-subject order balanced:

A. Static explanation (text + optional hand-authored figure).
B. Interactive approved scene (same learning objective, content-equivalent).

Each session:
1. **Pre-check** (2 questions): prior knowledge and one misconception probe.
2. **Learning activity** (8–12 min): A or B, think-aloud; observer notes control
   errors and confusion but does not teach.
3. **Post-check** (3 questions): core concept explanation + one near-transfer.
4. **Transfer question** (1 new-context problem, no hints).
5. **Short feedback**: clarity, cognitive load (1–5), confidence, and whether the
   scene helped or distracted.

## Measures

- pre/post normalized gain (per participant, not pooled as significance with a
  tiny n);
- transfer rubric score (0–3) by two independent reviewers, disagreements
  recorded;
- time to first correct explanation;
- control errors: play/pause, seek, slider, checkpoint;
- cognitive-load and preference ratings;
- accessibility observations: keyboard-only run and reduced-motion run.

## Sample and claims

Target n=8–12 volunteers, university-level STEM learners, recruited with consent.
This is a **usability/learning signal**, not a statistically powered efficacy
trial. Report individual and aggregate data, confidence intervals only if the
sample supports them, and explicitly retain negative cases. Do not claim mastery,
significance, or generalizable effectiveness from this sample.

## Materials

- Condition A/B content derived from the same benchmark case;
- approved production scene only (AI-generated research scenes are excluded);
- no personal data in transcripts; anonymous IDs;
- stop rule: any participant confused about “is this graded?” is corrected
  immediately because the scene is presentation, not assessment.
