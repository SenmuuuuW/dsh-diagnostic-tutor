## Why strict first-pass failed

The model still used natural but non-canonical shapes: `value` for `default`,
`field` for timeline target `property`, `prompt` for checkpoint body, bare
expression strings, `**` powers, missing primitive targets, and long alt text.
The Canonical Prompt made the rules explicit but did not guarantee compliance.

This is a **contract adherence failure**, not a renderer failure. The 11/11
repaired result is deterministic repair, not model learning.

## Decision result

- `v4s-bayes`: no-scene, counted as a **partial false negative** (a probability
  tree could help); 14/15.
- `v4s-game-theory`, `v4s-sonnet-form`, `v4s-connotation`: reasonable no-scene
  decisions.
