# v0.8.0 Real DSH E2E — approved scene playback

Environment: isolated `DSH_HOME=/tmp/udt-v08-live`, DSH `0.2.2-rc.1`, plugin
tarball built from `feat/v0.8.0-scene-engine`, flag
`DSH_DIAGNOSTIC_TUTOR_DYNAMIC_SCENES=1` for the enabled run. Credentials and
browser profile were temporary and were deleted afterwards. The real user DSH
profile was not touched.

## Fixture

A developer script seeded a course through the same validated runtime APIs
(`saveBrief` → assessment → curriculum → accept → begin → bind → lesson). The
lesson contains the one code-approved scene block `scene-unit` and a following
text block. The scene progress was seeded initially with an invalid old
fingerprint so restore behavior could be observed.

This is a fixture setup, not model-generated teaching and not an approval bypass:
the scene came from `APPROVED_SCENES` and would be rejected if changed.

## Observations (enabled)

1. Opened the session, chose **Learning map → Continue learning**.
2. Study opened in the right-sidebar full-screen mode; the scene rendered an
   SVG with the unit circle, sine curve, angle slider, narration and a 3.14s
   checkpoint.
3. Clicked the checkpoint: timeline moved to **3.14s**.
4. Changed the angle slider to **2.00rad**; graphic and progress updated.
5. Played briefly and paused. Runtime persisted:
   `stepIndex=0`, `finished=false`, `scenes['scene-unit']` with time around 3.15,
   `params.angle=2`, `playing=false`, `checkpointId=cp-pi`.
6. Set timeline to the end. The block remained on **Step 1 of 2**; playback
   completion did **not** complete the lesson or move to the text block.
7. Reloaded the DSH page, re-opened the lesson. The scene restored the persisted
   timeline position and angle and was **paused**, not autoplaying.
8. Pressed Continue; Study moved to the text block. No automatic knowledge-map
   or course completion occurred.
9. `/diagnostic-tutor/api/path` before/after showed attempt evidence count **0**
   and no lesson completion. The overview node count stayed **2**. No evidence or
   mastery was fabricated by scene interaction.
10. No uncaught browser exceptions.

## Disabled flag

Restarted the same isolated profile **without**
`DSH_DIAGNOSTIC_TUTOR_DYNAMIC_SCENES`. `GET /scene-config` returned
`{dynamicScenes:{enabled:false}}`. The same lesson block rendered **no SVG** and
showed:

> Dynamic scenes are disabled; showing the static explanation.

plus the required fallback text. Study Continue still worked.

## Limit of this E2E

- One approved fixture scene only; not a content library.
- The fixture was seeded by a developer script because the AI pipeline is not
  allowed to write production scenes.
- It exercises the real DSH host and production client bundle, but not a human
  learner.
