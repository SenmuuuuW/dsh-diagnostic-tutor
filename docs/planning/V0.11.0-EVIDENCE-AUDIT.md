# v0.11.0 Quiz / Evidence Audit

## Finding

Previous reports looked at `attempt.evidence` and saw `[]` after a quiz. That is
**not a bug**.

- `attempt.responses` contains the quiz answer.
- `recordBlockResponse` appends a neutral `practice` evidence entry to the
  **diagnosis node bound to the attempt**.
- `attempt.evidence` remains empty; it is reserved for completion references
  (`check`/`transfer`) used by course completion.
- Node state is unchanged; no mastery is inferred.
- Re-submitting the same block updates the response snapshot and does not append
  duplicate practice evidence for that attempt/block.
- A tutor must explicitly call `udt_map_update` with check/transfer evidence to
  move a node state.

## Verification

`tests/interactions.test.ts` now asserts attempt evidence is empty while node
practice evidence exists. The v0.10 Study/Quiz E2E behaviour is consistent with
this contract.

No auto-grading, auto-mastery or hidden evidence was added.
