# v0.11.0 Schema-Guided / Staged Generation

## Interface audit

DSH tools accept a JSON-Schema-like parameter spec (`defineTool`) and validate
tool arguments before execution. This is useful for **staged typed tools**, but
the current DSH/model interface used here does not expose a
`response_format`/JSON-Schema-constrained decoding switch for free-form
assistant output. We therefore did not fake a constrained-decoding experiment.

## Strategies

### A — v4 baseline

Single large free-form SceneSpec. v4 sealed: **0/11 strict**; deterministic
repair 11/11; visual 11/11.

### B — Schema-guided tool calls

Not executed as a full SceneSpec tool in this round. The DSH tool schema supports
nested objects/arrays/oneOf, but a full SceneSpec bridge tool plus isolated model
run was not implemented. A partial tool-schema-only result would not be a fair
comparison. This is recorded as **not tested**, not as a success.

### C — Staged generation (implemented)

Three model stages:

1. decision + metadata/properties/viewport/fallback/accessibility;
2. primitives only;
3. timeline/controls/checkpoints/narration only.

Deterministic assembly produces a SceneSpec; all normal validation still runs.

Real model: DeepSeek-V4.1-Flash, five cases drawn from the v4 development set
(not a new blind holdout).

| Metric | Staged v11 |
| --- | ---: |
| Cases | 5 |
| Raw strict first-pass | **1/5** |
| After deterministic contract repair | **4/5 scene visual** |
| Browser render | **5/5** |
| Semantic applicable | 1/5 |
| Semantic pass | 1/1 applicable |
| No-scene decision | 1 (Bayes, but staged generated a scene; compared as scene case) |

The staged model still used `Math.cos`/`Math.asin`, `Math.PI`, non-contract
expressions, and other drift. The functions were added to the canonical contract
only after this pilot; the result is a development measurement, not a new sealed
benchmark. Staging alone did **not** solve contract adherence.

## Conclusion

Do not scale to another large benchmark until generation uses a real typed
intermediate representation or schema-validated tool/stage output. Staging is a
useful decomposition, not a reliability fix by itself.
