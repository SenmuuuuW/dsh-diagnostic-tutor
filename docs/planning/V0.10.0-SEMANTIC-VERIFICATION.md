# v0.10.0 Semantic Verification (limited)

## Implemented

[`research/dynamic-lesson-engine/v4/semantic.mjs`](../../research/dynamic-lesson-engine/v4/semantic.mjs)

Supported constraint:

- **point-on-circle**: discovers a constant circle and a radius-driving point
  primitive (expression or timeline-track driven), samples parameter min/max,
  time 0/mid/end, and checks `|distance(point, center) - radius| <= tolerance`.
  Reference values belong to the case, not the model.

Result states:

- `pass` - explicit supported constraint passed;
- `fail` - a discovered point/radius pair violated the constraint;
- `unverified` / `not-applicable` - no supported constraint or no discoverable
  point pair. **Not counted as pass.**

## Real result

- 1/11 sealed scenes had an applicable semantic constraint
  (`v4s-unit-circle-tangent`); it passed after repair.
- 10/11 were **unverified**, not counted as conceptual success.
- A deliberately wrong radius expression was detected and a real model repair
  restored it in **1/1** attempt.
- No claim of general mathematical/algorithmic correctness.

## Not automated

- derivative/slope semantics beyond sampled coordinates;
- physical direction, energy and causal relations;
- sorting/search state invariants in generated text states;
- supply/demand equilibrium direction;
- label meaning, misconceptions, teaching sequence, cognitive load.

These require human educational review.
