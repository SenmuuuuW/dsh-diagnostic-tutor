# v0.10.0 Learner Pilot

**Not executed. 0 participants.** No learner data is simulated or invented.

## Ready materials

- static vs interactive condition design;
- pre/post-check and transfer rubric;
- think-aloud script;
- control-discovery task (play/seek/slider/checkpoint);
- anonymous data template;
- consent and withdrawal note.

## Pilot design

Pre-check (2), learning activity (8-12 min), post-check (3), transfer (1),
short interview. Within-subject balanced order; static and interactive versions
use the same objective and comparable content. Measures: individual normalized
gain (descriptive), transfer 0-3 with two raters, control errors, cognitive
load, continue interest, accessibility with keyboard/reduced motion.

Target n=8-12 university-level volunteers. Small n will not be reported as
statistically significant.

## What engineering evidence does not prove

Schema validity, visual gate, semantic point-on-circle and Study E2E do not
establish learning gain. The visual gate is not a teaching judge.
