# v0.11.0 Real Tutor Teaching Loop

## What was actually run

Isolated DSH `0.2.2-rc.1`, Universal Diagnostic Tutor skill installed at
`.agents/skills/universal-diagnostic-tutor` in a temporary workspace, diagnostic
tutor plugin installed in an isolated profile, DeepSeek-V4.1-Flash.

Real user prompt:

> I can calculate derivatives mechanically, but I do not really understand what
> the derivative means visually. Please diagnose my understanding and teach me.

Observed real tutor behaviour:

- invoked `udt_goal_create` for **Visual Meaning of the Derivative**;
- invoked `udt_path_get`;
- asked a diagnostic multiple-choice question about the learner's visual picture;
- used the skill's references (`routing.md`, `learning_runtime_contract.md`);
- no automatic mastery or evidence was fabricated.

Screenshot: [tutor diagnosis](../assets/v0.11-tutor-diagnosis.png) if captured;
the run transcript is recorded in this report.

## Not completed

- The interactive diagnostic question UI/state did not complete the full
  diagnosis in the automated browser session; a human-driven session is needed.
- There is no production Tool that lets the Tutor invoke the research
  staged-generation pipeline. A controlled bridge was not implemented.
- Therefore the chain **Tutor → Gap → Scene Generation → Approval → Study →
  Check → Tutor Next Step** is **not fully proven**. Only the real Tutor
  diagnosis start and the separately tested Scene/Study/Quiz path exist.

This is a blocker, not a successful end-to-end claim.
