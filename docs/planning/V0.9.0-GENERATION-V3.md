# v0.9.0 Generation v3 — real-model blind run

## Pipeline

```
Teaching case
→ needs-scene decision (may honestly say NO)
→ plan (if scene)
→ SceneSpec + explicit visual style contract
→ schema validation
→ static visual lint
→ browser render
→ manual review
→ (never automatic approval)
```

The decision is a first-class result. A scene is not forced when text, audio or a
static comparison is the better medium.

## New blind cases

10 cases created before the run in
[`v3/blind-cases.json`](../../research/dynamic-lesson-engine/v3/blind-cases.json):
language vocabulary, proof by contradiction, Big-O, photosynthesis, supply
shock, normal distribution, Newton's third law, functional groups, SQL inner
join, poetic meter.

Model: **DeepSeek-V4.1-Flash** via DSH `0.2.2-rc.1`, isolated profile. Raw
artifacts and browser screenshots are committed under
`research/dynamic-lesson-engine/v3/`.

**Important caveat:** the cases were created before the run, but the research
schema/linter compatibility was adjusted after batch 1 (textAnchor alias, empty
properties, metadata.topic, case-insensitive identifiers). This is not a pristine
blind holdout; no case-specific prompt was changed.

## Results

| Metric | Result |
| --- | ---: |
| Cases | 10 |

| Strict v0.1.0 schema first pass | **0/6 scenes** (shape drift: textAnchor, missing properties, metadata.topic) |
| Final v0.1.1 compatibility schema | **6/6 scenes** |

| Browser render | **6/6**, 0 exceptions |
| Candidate production approvals | **0** (none reviewed into production) |

The strict-schema failure is important: the model produced useful scenes but used
natural SVG spellings rather than the exact research contract. The v3.1
compatibility rules are now documented and tested; they are not a claim that the
original JSON was strictly valid.

## Safety

- no JavaScript execution from model output;
- no URLs, images, HTML, event handlers or `foreignObject` accepted;
- strict validator + expression allowlist;
- visual gate blocks missing visible paint, bad geometry and out-of-frame content;
- browser runs had no exceptions;
- no automatic approval or production write.
