# v1.0.0 Performance Snapshot

Measured on the isolated first-run profile (macOS, Node 24.16, DSH
0.2.2-rc.1), not a benchmark suite:

| Operation | Dataset | Measurement |
|---|---|---:|
| `GET /diagnostics` | 1 course, 3 nodes, 1 lesson | 4.2 ms, 6.7 KB |
| `GET /export` | same | 1.9 ms, 38.96 KB |
| `doctor --json` | same | 38 ms |
| storage `udt.json` | same | 40 KB |

These are smoke measurements, not a large-data benchmark. The local JSON
storage is synchronous in-memory reads with one write chain per plugin
instance; no cross-tab strong CAS is claimed.
